# Third-party notices

See [`go.mod`](../go.mod) for Go dependencies and
[`go.sum`](../go.sum) for their checksums.

Releases at <https://github.com/cozybadgerde/cress/releases> include
machine-readable `.licenses.csv` reports generated by
[go-licenses](https://github.com/google/go-licenses). Each row contains a
library path, license URL, and detected license name. Reports have no header.

Archives include generated license texts in `THIRD-PARTY-NOTICES.txt`.
These outputs are generated during release packaging, not maintained as
a dependency catalogue in this document.
